# Beyond the Code — My Story

A personal storytelling website created by **Shreya G.**, a Computer Science Engineering student, for the **iLEAD 2027 – Build Your Story Challenge**.

## 🌟 About the Project

Beyond the Code is a personal website that reflects my interests, aspirations, values, and journey of continuous learning and growth.

It features a modern, futuristic design with dark cosmic themes, purple and cyan gradients, and interactive elements.

## ✨ Features

* Personal storytelling and self-expression
* Interactive constellation background animation
* Responsive design for different screen sizes
* Smooth navigation and scroll effects
* Interactive cards and tabs
* Clean design with accessibility in mind

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations, and responsive layout
* **JavaScript** – Interactive elements and canvas animations

1. Clone this repository:

   ```bash

   ```
2. Open the project folder.
3. Open `index.html` in your browser.
